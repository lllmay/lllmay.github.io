# ملف أعمال ميّ عبدالعزيز

موقع ملف أعمال تفاعلي — أخصائية تسويق | Marketing Specialist.

## النشر على GitHub Pages
1. ارفع كل الملفات (index.html ومجلد assets) إلى المستودع.
2. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.
3. بعد دقيقة أو دقيقتين يصير الرابط جاهز.

## إضافة حملة جديدة
كل المحتوى داخل index.html في قائمة `BRANDS`: انسخ أي حملة وعدّل نصوصها، وضع الصور والفيديوهات داخل مجلد assets.
